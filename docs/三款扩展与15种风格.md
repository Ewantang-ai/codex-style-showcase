# 扩展示例与风格库

## 三款经过改编的示例

等距城市：中心区、工厂、科技园、公园、商业街、住宅、校园、码头、运动场使用不同几何与用途。广告牌沿建筑立面和透视摆放；日景用实体广告牌。品牌只作署名，不反复在口播里强调。

HUD扫描：画面扫描、目标发现、追踪、局部放大、状态更新和结果确认。面板应告诉观众「展示什么、用在哪里、效果能做什么」，不要只堆随机字符。

液态流动：落滴、拉丝、融合、液浪转场与字形凝聚。结尾署名可替换，不必在口播里反复念品牌。

像素以外的这三款入口分别为 `$isometric-city`、`$hud-scan`、`$liquid-motion`。本地预览分别用 `--style city`、`hud`、`liquid`。

## 15种原始风格

运行 `python tools/preview.py --style library --open`，进入原风格目录。每项可打开实际源码页面和原始提示词。

扁平矢量、线条艺术、等距城市、3D渲染、逐帧手绘、拼贴剪纸、液态动效、图形形变、包豪斯几何、合成波、极光玻璃、综艺动态大字、贴纸解说、像素世界、HUD扫描。

这是从固定版本公开源码整理的参考库，不含15支大体积原作者MP4、原作者采样音乐或完整音频生成环境。需要原作者影片请访问上游仓库；本地可看静音源码动画。部分字体以随包的开源字体替代，外观与原片会略有差异。贴纸解说保留在原始参考库，但没有作为本次三款演示的推荐成片风格。
