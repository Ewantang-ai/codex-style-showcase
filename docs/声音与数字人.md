# 用自己的声音和左下角小头像

## 首选声音来源

已有自己的录音就直接复用。需要禅镜时，在自己的账号中打开**数字人视频编辑页**，选择自己已有的声音，把最终台词填入文本区，检查页面是否已经生成可试听音频。仅保存自己被允许使用的试听音频，不提交视频生成。

平台的试听入口、免费额度与下载权限可能调整，以当前页面为准。没有直接下载时，先检查浏览器工具是否支持保存当前音频；若只允许播放，可在得到音频捕获授权、且不影响用户电脑使用的情况下录制播放。做不到时报告具体限制，不能绕过访问限制，也不能擅自跳到收费入口。

**独立“声音合成/文字转声音”的生成按钮可能按秒扣蝉豆。它和视频编辑页的试听是两个流程。本包不会替你点击收费生成。**

试听如果不完整、不是本人声线、出现多余开头音或句尾丢字，先修文本和试听结果；不要用大量切碎、变速来勉强拼成目标时长。完整核对英文词和专有名词。

## 本地对口型

MuseTalk官方项目：https://github.com/TMElyralab/MuseTalk 。本包提供流程说明，不附模型权重、Python环境或一键安装。使用者需按官方文档选择兼容Python、PyTorch、CUDA与模型版本，确认自己的设备空间和显存，再单独配置。

输入为自己的清晰人像视频或图片与最终音频。先做8秒样片，检查脸部边缘、闭口、张口和时间偏移，通过后跑全长。不能把8秒样片反复循环成整片冒充全长对口型。换声音要重新做嘴部动作。

示例命令的文件均由使用者提供：`python -m scripts.inference --inference_config 你的配置.yaml --version v15 --use_float16 --batch_size 1`。其他模型路径和参数按已安装版本的官方说明配置，不能把制作者的F盘路径复制到别人的电脑。

## 头像摆放

本系列为16:9，人物小窗放在左下角。先识别眼睛中点和双眼连线，用平滑的平移、旋转让脸在小窗内居中、眼线水平；保留自然动作，不拉伸五官。不能只移动整个小窗就当作脸已居中。

半身素材的衣服下沿贴小窗底部，避免悬空横截断；不加不合动作的桌子。绿幕用抠像，普通背景用人物分割或保留矩形小窗，不能把普通背景按绿幕参数硬抠。

## 字幕、声音和交付

下方字幕先按1080P约60–64像素试排，太长就按语义拆行，再看真实预览；不能只改一个字号数值而不看脸和字幕是否打架。

先保证人声，再配置乐。人声可从约-14至-13.5 LUFS开始调整，最终AAC真峰值通常控制在-1 dBTP以下。处理突出的字峰后再整体提高，配乐明显更低。以最终成片的实测和试听为准，不能只看归一化的目标参数。

检查完整句子、原有停顿、开头异常音、句尾、口型、字幕与画面动作。所有真实脸和声音只留个人工程，不提交公共仓库。
