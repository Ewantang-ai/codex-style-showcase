# 常见问题与交付检查

页面黑屏：先用预览工具启动本地HTTP服务；检查浏览器WebGL和控制台错误；检查是否完整解压字体、JSON、JS和运行模块。不要重新生成声音来解决页面黑屏。

中文成方块：检查像素例子的FusionPixel12.ttf与字体加载；不要偷偷换成普通系统字体。15风格原库中的部分字体采用随包开源替代。

改NPC台词没变化：实际入口加载quest-original-expanded.js；单独的quest-extension.js是维护副本，需同步到完整文件。每次同步都有备份。

对话和声音不同步：新声音使用新转写和真实时间点；正文、字幕、NPC和跑跳按同一条音频对齐。别只拉长静帧。

人声小：检查最终AAC响度、单字峰值、单声道转立体声是否衰减和配乐音量；不要把所有轨道一起抬高。

头像偏：先校正小窗内部的脸部中点、双眼角度，再设置左下角窗口的位置。

导出失败：先做3秒静音短片，确认Node、Chrome、FFmpeg和写入目录；没有模型时先完成动画，不能伪称完成对口型。

完整交付至少包含MP4、同版封面、最终台词、字幕、工程、依赖与素材许可。每条片检查开头钩子、运动中间帧、字幕安全区、人物边缘、人声、句尾和互动结尾；随机跳回同一时刻应得到同样画面。
