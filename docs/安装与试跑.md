# 从领取到第一次试跑

## 1. 下载、解压和检查

在版本页 Assets 下载 `codex-video-skills-v2.0.0.zip`。手机可以查看说明，制作建议在电脑上完成。GitHub连接受网络环境影响，打不开不代表文件缺失。

解压到你有写入权限的目录。检查根目录有README、skills、docs和tools；不要在ZIP内直接运行文件。

## 2. 使用或安装Skill

直接把整个目录交给Codex即可。可选安装：先查看 `安装Skill.ps1`，在PowerShell进入解压目录后运行 `./安装Skill.ps1`，默认复制7个制作入口到本机Codex的skills目录；已有同名目录先备份。

需要29个进阶知识Skill时才运行 `./安装Skill.ps1 -IncludeExtras`。安装不会下载模型或提交收费服务，不会改变系统执行策略。若脚本被设备策略禁止，可以让Codex按相同规则手动复制，或直接读取完整目录。

## 3. 不安装渲染依赖也能先预览

你需要Python 3和支持WebGL的现代浏览器。在解压目录执行：

```text
python tools/preview.py --style pixel --open
```

没有python命令但装了Windows Python启动器时，可改为 `py -3 tools/preview.py --style pixel --open`。终端会显示真实的本地地址；结束后在启动终端按Ctrl+C关闭。不要把示例localhost地址直接当作你这台电脑的固定地址。

可选style：pixel、city、hud、liquid、library。library是15种原风格的目录。浏览器直接双击HTML时，模块和fetch可能被限制，所以使用这个仅监听127.0.0.1的本地服务。

## 4. 导出一个短片

需要Node、Chrome和FFmpeg。在解压目录运行 `npm install` 安装package.json里的渲染依赖；这会联网下载软件包，不调用AI生成。Chrome可以用CHROME_PATH指定，FFmpeg可以用FFMPEG_PATH指定，或加入PATH。

```text
node tools/render.mjs --style pixel --duration 3 --fps 25 --out outputs/pixel-test.mp4
```

先看3秒短片，再导出完整例子：去掉 `--duration 3`。默认导出静音画面，完整像素示例约60.6秒。它没有偷偷使用作者原音。

如要接自己的录音、字幕和小头像，先按声音教程完成真实对齐，再交给Codex组合；不要把示例的旧时间表直接当成新语音时间。
